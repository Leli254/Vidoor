# Code of Conduct

## Our Standards

We are committed to maintaining a respectful, professional, and collaborative environment.

Participants are expected to:
- Be respectful and constructive
- Focus on technical collaboration
- Accept feedback professionally
- Avoid harassment, discrimination, or disruptive behavior

---

## Unacceptable Behavior

Examples include:
- Personal attacks
- Harassment or intimidation
- Discriminatory language
- Spam or malicious contributions
- Deliberate disruption of discussions

---

## Enforcement

Project maintainers reserve the right to remove contributions or restrict participation for behavior that violates this Code of Conduct.

---

## Scope

This Code of Conduct applies to:
- GitHub discussions
- Issues
- Pull requests
- Project communication channels

---

By participating in this project, you agree to uphold these standards.
