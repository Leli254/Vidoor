# Security Policy

## Supported Versions

Only the latest stable release of Vidoor receives security updates.

---

## Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities.

If you discover a security issue:
- Open a private security advisory on GitHub
- Or contact the maintainers directly

Please include:
- Description of the issue
- Reproduction steps
- Potential impact
- Relevant logs or screenshots

---

## Scope

Security issues may include:
- Remote code execution
- Unsafe subprocess execution
- Path traversal vulnerabilities
- Dependency vulnerabilities
- Arbitrary file write behavior

---

We appreciate responsible disclosure and will investigate valid reports promptly.
